## 3. 当前生效参数（**以此为准**）

### 3.1 连续强度与分支归属

```
driveLevel(item, speed) = max( speed / 48,
                              0.62 × clamp((shotPower − 55) / 45, 0, 1) )
DRIVE_FLOOR = 0.45
```

- `shotPower = floor((s.shotCommand % 363600) / 3600)`，来自出杆指令，**两条路径都传**：回放动画 `host._returns.push`（`pool-view.js` 第 232 行）与 snapshot 直推（第 144/145 行）。
- 局部几何：`offset = |(center−pos) × û|`（偏心距）、`along = (center−pos) · û`（到袋心前向距离），`û` 为实测入射方向。

| 条件 | 分支 | 表现 |
|---|---|---|
| `drive < 0.45` | 原直落 | 一次撞壁后 80ms 下沉，轻推应有的安静感 |
| `offset ≥ 11` **或** `along < 0` | `rattle` 绕袋螺旋 | 斜擦 / 已掠过袋心的球 |
| 其余（`offset < 11` 且 `along ≥ 0`） | `rebound` 轴向往返 | 正面近轴球 |

两分支**平铺覆盖**所有 `drive ≥ 0.45` 的落袋，不存在空档；`item.rattle` / `item.rebound` 可强制开关，且已进动画缓存签名。

### 3.2 绕袋螺旋 `rattlePlan`

| 参数 | 当前值 |
|---|---|
| 圈数 | `turns = .25 + 1.9×level² + .15×min(1, offset/24)` |
| 半径 / 终点半径 / 下沉 | `16 → 2.2` / `RATTLE_SINK=9` |
| 角速度 / 引入速度 | `RATTLE_OMEGA=.031` / `RATTLE_SPEED=.35` |
| 引入段 | Hermite，`44 ~ 176ms`（上限由 128 提高，长斜线起点不再首帧冲刺） |
| 总时长 | `span ≤ 500 − start`，`dropAt = rattle.end` |
| 擦壁声 | `1 + round(2×level)` 次，强度递减 |

### 3.3 轴向往返 `reboundPlan`

| 参数 | 当前值 |
|---|---|
| 次数 | `maxBounces = 1 + round(7.4 × level³)` |
| 初速 / 速度保留 / 收窄 | `v0=.45+.12×level` / `rest=.90+.04×level` / **`shrink=.735−.04×level`** |
| 边界 | 后端点由**外扩后的**袋后壁几何探测（`clearance < R`），前端为袋口颚部；保留入射点横向分量避免首帧跳变 |
| 上限 | `REBOUND_MAX_TIME=320ms`；`dropAt` = 最后一次撞击时刻 |

**力度分级实测（正面直进，中袋/角袋满力同为 8 下）**

### 3.4 可见性与连续性

- 动作期 `depth` 上限：绕袋 **0.16**、往返 **0.12**（旧值 0.9 / 0.35 会把球裁掉，这是"钻进去"的第二层根因）；末次接触后按常规 **80ms** 升到 1。
- 球半径随 `depth` 缩放 `1 − .16×depth`，动作期几乎不变。
- 出袋通往回球管道的目标速度 clamp 到 **±0.55**，长绕袋收尾不跳帧。
- 286 次全力落袋**最大单步 2.272**（4ms 网格，阈值 2.3）。

## 12. 进洞撞击改为厚实木头、回音收敛（2026-11-10，十五）
