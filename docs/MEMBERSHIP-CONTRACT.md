# 成绩记录会员规则

用户最新要求（2026-10-31）：游戏次数继续不限，匿名和登录用户均可玩；仅登录账号可以记录累计成绩。每天免费记录一次，会员不限记录次数。会员价格为月付 9 USD、年付 59 USD，支付渠道为 Creem。

用户已选择：每日首局已完成的登录对局自动使用一次免费记录资格，正负分都计入；会员不限。日界暂沿用 UTC 00:00 实现默认值。不能接受客户端自报分数；必须由服务端比赛结果生成积分。旧的“所有登录对局均累计”条款由本次规则调整覆盖。

实施边界：Creem 商户与具体售卖商品尚未获本项目验证；未创建真实商品、未扣款、未发放会员。后续会员资格只从验签且去重的可信支付/订阅事件更新，并处理续订、取消、到期和退款。支付回跳页面、前端标志或本地预览不能授予会员。

支付配置要求：Creem API key、Webhook secret、月付与年付真实 product ID 以及部署的 HTTPS 回调地址。目前均未完成配置验证，购买按钮保持禁用。回调必须按 [Creem 官方签名说明](https://docs.creem.io/code/webhooks)验证原始请求体的 HMAC-SHA256，并对事件去重；不能仅凭 checkout 回跳或未验证的元数据授予会员。

会员只影响成绩记录次数，不应影响骰子、移动规则、胜率或免费游玩的次数。没有会员的玩家在免费记录资格耗尽后仍可继续玩。

Checkout 基础接口现为 `POST /api/billing/checkout`，提交服务端方案名及 UUID requestId。默认测试模式，购买前仍须核对 Creem 商品 USD 金额和周期分别为 9/月与 59/年；当前尚无自动商品核验和沙盒成功验证，页面购买保持禁用。若服务端请求结果不确定，不自动重复创建，保留账本供后续对账。
