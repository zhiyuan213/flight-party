# 四子连珠：通透圆片、落子声音与连线反馈（2026-11-13）

用户参考：[原图](design/four-feedback-reference-20261113.png)。此轮为已授权的本地视觉和音效改进，不代表最终视觉验收通过。

- 默认棋盘为浅桃木，双方圆片改为青绿与粉红：高光外沿、内凹色环、通透镜面。悬停、半透明落点、下落和静止棋子使用同一素材；节日配色和个人已装配徽章保留。商城四个圆片预览与局内共用底图。
- 每次新增一颗棋子，使用当前 WAAPI 动画时间触发轻释放音、首次触底声和较轻的回弹声。没有通过鼠标点击时间猜测落地。声音为本地 Web Audio 合成，不依赖远程音频或安装。
- 同色直线连续 2 颗柔光提示，3 颗加强呼吸光；横、竖、两条斜线均支持。必须由原规则或服务器确认获胜，才显示胜利光环、连线和有限粒子。没有改动胜负判定、回合或计分规则。
- 最后一颗落稳后触发胜利反馈与原有结果音，棋盘保留 1600ms 后再显示结算弹窗；同一局不重复播放，本地下一局即使同手数同胜方也可再次播放。
- 重置、退出、替换棋盘、隐藏页面时取消旧落子与音效；减少动态效果模式立即落稳并保留一次接触音及静态连线高亮。首个完整快照、重复快照和跳过多手的快照不补播历史下落。
