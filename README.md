# Flight Party · v0.7.2 UI预览交接版 · 2026-10-31

**本版简化界面；真实联机、登录、自动保存和防篡改交给后续Codex实现。** 保留道路贴合、3D骰子、配色、飞机编号/接触阴影及本地玩法。没有真实账号、持久积分、在线榜单、服务端额度或跨设备房间；所有模拟状态均须标注“Preview / 示例数据”。

## 最新流程

| 入口/区域 | 后续真实功能要求（当前UI预览） |
|---|---|
| 快速匹配 | 直接加入有空位的公共等待房；无房则自动建房；满员提前开始，最多等30秒后机器人补齐 |
| 创建房间 | 进入等待房邀请朋友；当前真人全部点“准备起飞”后，整房匹配其他人，30秒未满机器人补齐 |
| 登录账号 | 自动保存服务器确认的完整成绩，包括负积分；不再手动上传或结算后认领 |
| 匿名玩家 | 可直接玩，不保存累计积分/局数、不入榜 |
| 排行榜 | 积分榜、对局数榜各Top10；移除胜利榜/胜率显示 |
| 防篡改 | 后端判定骰子、移动、回合、机器人、名次和统计；拒绝客户端自报分数，重复请求不重复加分 |

30秒从进入公共匹配开始，等待朋友时不倒计时，加入或离开不刷新时限。线上UI默认经典四席，省去匹配人数/模式/机器人设置；这不是全游戏永久锁四人，本地练习仍支持2–4阵营。好友全员准备后允许陌生匹配玩家填空席，朋友保留原房间和席位。

正式开局时固定账号归属，退出登录也会记录该局完整结果；匿名在局中登录默认从下一局开始记录，输赢均计入已完成局数。

普通用户每日20局、会员无限保留；匿名同20局与UTC重置仍为建议。邮箱+密码注册/登录无邮箱验证码，保留Google/GitHub入口。断线/主动下线仍要求机器人接管原席位，重连恢复；表情后续应广播至全房间。

**本地引擎未修改。** 后续需实现前两名各自两架飞机到终点即结束，名次积分+2、+1、-1、-1，其余按完成数量/进度排名。完整规则及防篡改验收见 [`docs/V07-CONTRACT.md`](docs/V07-CONTRACT.md)，当前引擎差异见 [`docs/RULES.md`](docs/RULES.md)。

原设计图、用户反馈在 `docs/design`，继续作为开发参考。实际视觉边界见 `docs/VISUAL_ACCEPTANCE.md`，实测记录见 `docs/QA.md`；历史视频和旧测试不能证明本轮联网功能已完成。

## Windows启动

1. 完整解压，不要直接在ZIP里运行。
2. 有Node.js时双击 `start-windows.bat`，或在目录运行 `node server.mjs`。
3. 打开 **http://localhost:8080**，保持命令窗口开启。
4. 没有Node.js也可安装Python 3后运行 `python server.py`。

不需要npm install，不需要联网加载素材。不能直接双击index.html，因为ES模块需要HTTP服务。

## v0.6骰子升级（保留）

- **真实六面模型**：圆角网格、蓝色凹陷点数、连续曲面与光照；不再拼接CSS平面。
- **1120ms动画**：翻滚、轻跳、落地回弹，最终结果面朝向玩家。结果仍来自原规则模块，动画不重新抽取点数。
- **兼容渲染**：优先WebGL；无法使用GPU时，以软件3D投影和光栅化同一模型，不退回旧CSS骰子。
- **交互**：翻滚结束再开放飞机选择；支持减少动画、切换语言、取消旧对局及结果文字提示。
- **v0.6历史验证**：当时24项测试通过，浏览器实际视觉检查覆盖软件3D路径；GPU WebGL画面和真实手机性能尚未实测。

## v0.5保留内容

## 已有玩法与效果

- 首页、大厅、对局、结算四个界面。
- 2–4方，真人/电脑/关闭席位，每方两架飞机；真人在同一设备轮流游玩。
- 电脑自动选择、15秒超时托管、安全格、撞机回基地、排名。
- 默认固定视角2.5D：独立棋格侧面、倒角、接触阴影、切角基地和凹陷停机位。
- 撞击110ms停顿、1370ms弧形旋转返回、180ms落地回弹；路径线、烟团、星星和BOOP与随机撞击音效共用接触事件。
- 起飞、落地、掷骰、胜利音效，音效开关、音量和减少动画选项；可选背景音乐默认关闭。
- 派对模式单独开启，每轮二选一事件投票；经典模式无投票。
- Try a bump结束后恢复原对局；Record preview可导出含音轨的WebM棋盘录屏。

## 验证与边界

v0.6.2历史基线的26项自动测试通过，包括原规则与100场模拟、棋盘动画、道路角点/边缘贴合、投影直线与高度性质、七种尺寸下的归一化形状和可见性，以及骰子几何与动画。该轮实际浏览器检查为1363×936桌面；此前手机布局与骰子尺寸验证保留在QA历史段落中。v0.7实测记录已保留在QA；本轮v0.7.2简化匹配/自动记录流程需单独验收，未预先宣称通过；GPU画面与实体手机性能仍待实测。

**棋盘仍是预渲染素材与程序几何组成的2.5D画面，骰子则是独立的真实3D模型。** 整体实时3D棋盘的实验Three.js路径保留，未验证达到设计图精度。飞机没有独立表情/螺旋桨骨骼动画，旗帜布面为静态造型。

本版仍不是逐像素复刻：地面依据机场素材实测校准，飞机继续使用固定视角图片；海面较亮，手机上的机身编号较小。中文切换覆盖核心操作，部分文案仍为英文。任何账号、榜单、额度、会员或房间示例均仅用于评审布局，不能宣称真实服务成功。

## 给下一位Codex

先读 `AGENTS.md`、`docs/HANDOFF.md`、`docs/V07-CONTRACT.md`、`docs/RULES.md`、`docs/VISUAL_ACCEPTANCE.md` 和 `docs/QA.md`。当前交付范围是UI；后续功能需求已记录，不能因旧契约曾描述接口就把服务端功能写成已完成。以v0.6.2道路校准为视觉基线，不把局部认可当作整体最终验收。

| 文件 | 职责 |
|---|---|
| dist/engine.js | 原v0.1规则模块，逐字未改 |
| dist/fallback.js | 默认2.5D棋盘、素材、编号和撞击动画 |
| dist/ground-projection.js | 固定道路内沿标定、地面射影映射和局部深度比例 |
| dist/palette.js | UI与棋盘共用阵营材质颜色 |
| dist/scene.js | 实验Three.js渲染路径 |
| dist/app.js | 大厅、回合、计时、电脑、投票、录屏及玩家/骰子UI |
| dist/die-geometry.js | 六面圆角骰子网格、凹点、面值与结果朝向 |
| dist/die3d.js | WebGL/软件3D渲染、1120ms动画、取消与减少动画 |
| dist/audio.js | WAV音效、音量、录音音轨、音乐 |
| dist/reaction-preview.js / .css | 本地发送者头像、昵称、表情浮泡与玩家头像角标预览 |
| dist/visual-v2.css至visual-v6.css | 依序加载；v5保留整体布局，v6仅覆盖骰子区域 |
| dist/assets | 图像、字体、音效 |
| scripts/build_audio.py | 可复现原创音频素材 |
| tests | 规则、动画、原逻辑哈希与视口几何检查 |

测试：`npm test`。无需安装测试依赖，只需Node.js。Three.js MIT与Nunito字体许可证随包附带；图像来源和完整v0.5提示词见 `docs/ASSETS.md`。
